# Task Manager App

## Features

- User Registration
- User Login
- JWT Authentication
- Create Task
- Update Task Status
- Delete Task
- Todo / In Progress / Done

## Tech Stack

Frontend:
- React
- Bootstrap
- Axios

Backend:
- Node.js
- Express.js

Database:
- MongoDB Atlas

Authentication:
- JWT
- bcryptjs

## Assumptions

- Each user can manage their own tasks.
- Tasks belong to authenticated users.

## Tradeoffs

- No drag and drop functionality.
- No due dates or reminders.

## Technical Decisions

- React for fast UI development.
- MongoDB Atlas for cloud database.
- JWT for stateless authentication.

## Run Locally

Backend:

npm install
npm run dev

Frontend:

npm install
npm run dev
